- `src/sharing.js`: explicit sharing-round ancestry/hash; base/master/incoming record groups; owner conflict choices; incoming-approval confirmation; atomic linked-history validation; preserved complete merge parents; stable source and baseline IDs.
- `src/workflow-ui.js`: walkthrough, Ask the product, and Shared-file review screens. Existing Google-inspired visual language remains consistent.
- `src/demo-story.js`: complete fictional walkthrough → approved R2 → team checks → fraud-only R3 change.
- Optional AI adds cited handbook-section drafts, comparison of candidates against agreed rules, and explanation of selected approved context. Selected passages can be chosen from long sources. Provider secrets remain backend-only; no account/key has been provisioned.
- Source import cancellation now terminates work when its dialog closes. Named perspective changes clear prior answer context. Locking clears plaintext request/candidate/comparison state.

New exports use schema 4. Schemas 1/2/3 upgrade; future schemas reject. The previous schema-1 encrypted example was opened and upgraded successfully. Review copies preserve merge archives while using a new identity and dropping the original sharing round. Preserve original files before upgrading.

## Remaining boundaries

Live Supabase deployment, real user Auth, real provider output, extraction/answer quality evaluation, and multi-connection PostgreSQL contention require external setup. Follow AI_SETUP.md with secrets configured in the backend, never in chat or public files. The manual end-to-end product is usable without AI.

Manual scope review is required. Staleness compares actor/condition/outcome/applicability exactly; it is not a semantic equivalence model. A wording change to those fields may require re-review. QA suggestions and verification are self-reported; no tests execute and artifacts are not independently inspected. An acknowledgment never marks a task completed or creates a pass.

Shared files are explicit record-group merges, not live multi-user editing. Incompatible linked branches fail without changing the master. Both parent histories remain encrypted in the project. Ten merge archives and the overall 10-million-character bundle limit bound storage; the shared base and archives count toward it. No matching anchor means separate review, not guessed ancestry.

OCR, audio transcription, connectors, enterprise identity, shared cloud storage/jobs, exhaustive browser support, and production hardening are later extensions. No superiority claim over frontier AI models is made; the configured provider determines reasoning quality.
